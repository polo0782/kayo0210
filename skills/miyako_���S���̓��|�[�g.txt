B-01. 「〜なんだよなー。」（感嘆型語尾）
      → 好きなものへの感慨を締める。余韻を残す柔らかい終わり方。
      例：「パークハイアット、何度来てもここの重厚感やタイムレスな魅力好きなんだよなー。」

B-02. 「〜かもしれない。」（可能性型語尾）
      → 断言を避け、思索中の感覚を残す。読者が自分で補完できる余地を作る。
      例：「大阪出身だからか、歳を重ねてきたせいか、最近ちょっとだけおせっかいかもしれない。」

B-03. 「〜気がする。」（感覚型語尾）
      → 確信ではなく感覚として語る。価値観投稿・人生観投稿で多用。
      例：「着るものがもたらす力をたくさん感じた夜でした。」

B-04. 「〜からかもしれない。」（理由後置型）
      → 感情の理由を後から補足するスタイル。思考の流れをそのまま文章にする。
      例：「作り手さんの想いを纏うというモードは同じだよなーと感じたからかもしれない。」

B-05. 短文→改行→感情一言（構造パターン）
      → 事実を先に書き、改行後に感情の一言を添える構造。後半の一言に全感情を乗せる。
      例：「わたしは大阪出身なせいか、歳を重ねて来たせいか、最近ちょっとだけおせっかいかもしれない。\nでも、お声がけしてみてよかった。\nおじいさん、笑ってくれてよかった。」

B-06. 「〜。〜。〜。」（体言止め的な短文連打）
      → 短い文を連続させてテンポを作る。気持ちよく読める旅行記・体験記投稿に多い。
      例：「お天気はずーっと晴れていて。温泉はどこの宿も泉質最高だし、芝生見つけると、ついつい寄り道しちゃってチルしたり」

B-07. 「〜てほしい。〜てほしい。」（願望の反復）
      → 同じ願いを形を変えて2回繰り返す。感情の強さと包み込む優しさを同時に演出。
      例：「傷つかないでやめないで負けないで！」

B-08. 「わたし」（ひらがな一人称）
      → 「私」ではなく「わたし」。柔らかさ・素直さのニュアンス。全投稿で一貫。

B-09. 「〜で、〜で、〜で、〜。」（列挙型長文）
      → 体験・要素を「〜で」で繋ぎながら積み上げていく構造。読点を使った連続感。
      例：「嬉野で茶摘みして、窯元訪ねて、作家さんたちと沢山話して飲んで食べて、お天気はずーっと晴れていて。」

B-10. 「〜なーって。」（伝聞・内省型語尾）
      → 自分が思ったことを「誰かに話すように」書くスタイル。親密さと自然体を演出。
      例：「着物の話から、神話の話まで実はいろいろ繋がってて、普段の友人たちとの会話とまた違う面白い時間でした。」

B-11. 「〜てよかった。〜てよかった。」（感謝の反復）
      → 同じ「よかった」を繰り返して感情を深める技法。単純なようで心に刺さる。
      例：「お声がけしてみてよかった。おじいさん、笑ってくれてよかった。」

B-12. 「〇〇的な」「〇〇感」（感覚表現の造語化）
      → 「タイムレスな魅力」「重厚感」など、感覚を名詞化して具体的なイメージを作る。

B-13. 感嘆符「！」の使い方（使いどころを絞る）
      → 応援・エール投稿だけに集中して使う。普段は使わないので、出ると強く読める。
      例：「挑戦してる人は格好いいよ！すごいよ！」

B-14. 「〜。そう、〇〇。」（補足型改行）
      → メインの言葉の後に「そう」を置いて強調する。着物投稿でブランドや場所名を添えるときに使う。

B-15. 「—— 」（ダッシュ記号での場面転換）

D-05. 「天然の色彩のやわらかな力」
      → 化学染料と天然染料の違いを「力」という言葉で表現。触れる前から感じられるエネルギー。

D-06. 「循環こそが着物の魅力」
      → 使い続け・手を入れ・また使うというサイクルを「循環」と称する。サステナビリティよりも深い概念。

D-07. 「ご縁の深さ」
      → 人と人の繋がりの強度を「深さ」という比喩で測る。浅い縁・深い縁という感覚的な分類。

D-08. 「人生の原点にあった夜」
      → 入籍前夜のエピソードを「原点」と表現。夫婦関係の根を「その夜」に置く。

D-09. 「着物で変身できる」
      → 服を着ることの変容的効果を「変身」という言葉で表現。コスプレではなく、自分の別の面を引き出す。

D-10. 「旅でしかできない学び」
      → 現地体験の独自性を「旅でしかできない」と限定して価値を高める表現。

D-11. 「言葉には言った人の質が宿る」
      → 匿名の言葉への批評。言葉を鏡として見る視点。

D-12. 「良いところを見つける目を育てる」
      → 審美眼の話を「目を育てる」という成長の比喩で語る。自分が変わることで世界が変わる。

D-13. 「服の顔が変わる」
      → 同じ服でも着こなし方で印象が変わることを「服の顔」として擬人化。

D-14. 「心のドアをバタンと閉める」
      → ドアスラムの感覚の視覚化。感情の切り離しを「物理的なドア」で表現。

D-15. 「体験と学びで育てるもの」
      → 美意識・感性を「育てる」と表現。生まれつきではなく後天的に獲得できるという信念。

D-16. 「小さな幸せのひとつ」
      → 日常のかけらを「幸せ」という大きな言葉で呼びながら「小さな」で謙遜する。大げさにならない共感技法。

D-17. 「それが自分だとわかる整理感」
      → MBTIや自己分析で「腑に落ちた」感覚を「整理感」という造語で表現。

D-18. 「空気が変わる場所」
      → 着物のパーティー・職人の店・温泉宿——場所の持つ雰囲気変換力を「空気」で比喩。

D-19. 「また来るね、またはないのだと気づいた」
      → 愛犬との別れの話で使った表現。「また」という日常語が突然「過去」に変わる瞬間の衝撃。

D-20. 「核にある好きは変わらない」
      → 変化の多い日常の中でも変わらない「核」という概念。自己同一性を「核」という比喩で表現。
